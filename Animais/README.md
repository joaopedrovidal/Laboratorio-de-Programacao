# 04 - Lista de atividades (Extra)
Utilizando um exemplo de heróis em Java conseguimos abordar de forma prática o conceito de classes, objetos, encapsulamento, herança, polimorfismo e abstração.

Para consolidar o aprendizado, realize o que se pede:

01 - Crie um novo Projeto Animais.

02 - Cada animal possui nome, idade e cor.

03 - Crie subclasses Cachorro, Gato, Cavalo que herde de Animais e implemente o método emitirSom().

04 - Adicione um método para modificar o tipo de som (emitirSom) de um Animal.

05 - Crie uma classe Veterninario e onde vai existir uma lista de animais (ArrayList<Animal>) e adicione objetos de diferentes subclasses (Cachorro, Gato, Coelho). Percorra a lista, chame o método emitirSom() para cada animal e o adicione na "carrocinha".
